# Theme System

This directory manages the Material UI Design System.

## 📜 Rules

1. **SCSS + TS Hybrid**:
   - SCSS variables used for global tokens.
   - TypeScript objects (`theme.ts`) used for MUI Theme Provider.

2. **Component Overrides**:
   - `components.ts`: Customizes MUI component styles globally.

## 📂 File Structure

- `scss/`: SCSS tokens (colors, typography).
- `theme.ts`: Main theme configuration.
- `typography.ts`: Typography settings.
- `components.ts`: Component overrides.
