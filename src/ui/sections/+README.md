# Sections Layer

This directory contains larger organizational components that are specific to certain sections of the application or generic enough to be reused as major UI blocks.

## 📂 Structure

- `forms/`: Complex form layouts and compositions.
- `modals/`: Modal dialog contents and wrappers.
- `tables/`: Data table configurations and compositions.
- `tabs/`: Tab navigation and content groups.

## 📝 Usage

These components typically aggregate `components` and `elements` to form functional units but do not necessarily define the entire page logic (that belongs in `views`).
