- [x] **ARCH-001**: Convert route pages to Server Components
  - Remove `"use client"` from route `page.tsx` files
  - Move client logic to child components
  - Files: All `/app/admin/*/page.tsx`
  **Impact**: SSR benefits, SEO | **Effort**: 2-3 days | ✅ **DONE**

- [x] **ARCH-002**: Implement `middleware.ts` for auth
  - Replace client-side redirect in `src/app/page.tsx`
  - File: `src/middleware.ts`
  ```ts
  export function middleware(request: NextRequest) {
    const token = request.cookies.get("token");
    if (request.nextUrl.pathname.startsWith('/admin') && !token) {
      return NextResponse.redirect(new URL('/login', request.url));
    }
  }
  ```
  **Impact**: Faster auth redirects | **Effort**: 4 hrs | ✅ **DONE**
